# ECE 2171 Lab 4 Starter Code (Fall 2026)

Starter files for Lab 4: GPIO without high-level abstractions (STM32 registers on the Particle Photon).

This repository contains four Particle Workbench projects: `Lab4a`, `Lab4b`, `Lab4c`, and `Lab4d`. Each `src/Lab4x.cpp` file contains comments describing the steps to implement; the code is yours to write.

## Getting your own copy

1. Click **Use this template** (top right) and select **Create a new repository**.
2. Name your repository `ece2171-lab4-<username>`, set the visibility to **Private**, and click **Create repository**.
3. In your new repository, click **Code**, select **HTTPS**, and copy the URL.
4. In a VS Code terminal: `cd H:\ECE2171` then `git clone <your-copied-repo-URL> Lab4`
5. In VS Code, choose **File -> Open Folder** and open the `Lab4a` folder (later `Lab4b`, `Lab4c`, `Lab4d`).

See the Lab 4 handout on Brightspace for the full instructions.
